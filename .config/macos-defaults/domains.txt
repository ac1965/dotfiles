# macOS defaults.zsh の backup-all / restore-all が対象にするドメイン一覧。
# '#' 始まりの行と空行は無視される。1行1ドメイン。
# ここに書くのはドメイン名だけで、実データ(plist)は含まない。実データは
# private archive 側(.local/state/mac-defaults-backup)で暗号化して管理する。
# 追加/削除は自由に行ってよい。

# Dock(位置・自動非表示・アイコンサイズ・Mission Control)
com.apple.dock

# Finder(表示形式・隠しファイル表示・サイドバー)
com.apple.finder

# トラックパッド(タップ・ジェスチャー)
com.apple.AppleMultitouchTrackpad

# 入力ソース切り替え(英数/かな 等のショートカット)
com.apple.HIToolbox

# スクリーンショットの保存先・形式
com.apple.screencapture

# キーボードショートカットのカスタマイズ
com.apple.symbolichotkeys

# キーリピート速度・外観(ダーク/ライト)等のグローバル設定
NSGlobalDomain

# ファイル拡張子ごとのデフォルトアプリ関連付け(LaunchServices)
com.apple.LaunchServices/com.apple.launchservices.secure

# Safari(ホームページ・ダウンロード先・検索エンジン・AutoFill 等。
# ブックマーク/履歴/拡張機能の有効化状態は plist 管理外(~/Library/Safari/ の
# SQLite)のためここではカバーされない)
com.apple.Safari

# メニューバーのアイコン表示/非表示・並び順
com.apple.systemuiserver

# 日本語入力の変換設定・ユーザー辞書関連
com.apple.inputmethod.Kotoeri

# Control Center の項目表示(Wi-Fi/Bluetooth/バッテリー等、Sonoma以降)
com.apple.controlcenter

# メニューバー時計の表示形式(24時間表記など)
com.apple.menuextra.clock
